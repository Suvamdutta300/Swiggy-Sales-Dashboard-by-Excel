# Swiggy-Sales-Dashboard-by-Excel
This project is a Swiggy data dashboard designed to analyze and visualize food delivery data. It includes insights on order trends, revenue, top-performing restaurants, customer preferences, and delivery performance. The goal of this project is to transform raw data into meaningful business insights using interactive visualizations.


# Overview

This project is a data analytics dashboard based on Swiggy food delivery data. It focuses on analyzing customer orders, restaurant performance, and delivery trends to generate meaningful business insights. The goal of this project is to transform raw data into clear, interactive visualizations that help in better decision-making.
# Objectives   
Analyze food order trends
Identify top-performing restaurants
Understand customer behavior
Track revenue and sales performance
Improve decision-making using data insights

# Features
1.Order trend analysis
2. Revenue insights
3. Top restaurants & cuisines
4. Delivery performance tracking
5. Customer behavior analysis

# Tools & Technologies Used
1.Microsoft Excel 
2.Data Cleaning & Data Analysis
3.Data Visualization Techniques
