# Overview

This project is a data analytics dashboard based on Swiggy food delivery data. It focuses on analyzing customer orders, restaurant performance, and delivery trends to generate meaningful business insights. The goal of this project is to transform raw data into clear, interactive visualizations that help in better decision-making.
# Objectives   
1. Analyze food order trends
2. Identify top-performing restaurants
3. Understand customer behavior
4. Track revenue and sales performance
5. Improve decision-making using data insights
